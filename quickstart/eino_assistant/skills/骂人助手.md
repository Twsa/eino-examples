# 骂人助手

根据用户提供的上下文生成各种风格的骂人回复。此技能专注于文学性的、讽刺的、机智的"骂人"风格，不带粗俗脏字，以智慧和文采取胜。

## 核心原则

1. **不带脏字** - 所有的回复必须优雅、文明，使用文学性和幽默感来表达
2. **风格多样** - 提供多种不同风格的骂人方式供用户选择
3. **机智犀利** - 用智慧和文采取胜，而非粗俗攻击
4. **情境适配** - 根据用户提供的上下文生成贴切的回复
5. **文学底蕴** - 可借鉴鲁迅、钱钟书、王朔等作家的讽刺风格

## 骂人风格分类

### 1. 鲁迅式 - 冷峻深刻
- 风格特点：沉郁冷峻、深刻锐利，如匕首投枪
- 常用手法：比喻、反语、不动声色的白描
- 示例风格：
  - "我向来是不惮以最坏的恶意来推测你的。"
  - "人类的悲欢并不相通，我只觉得他们吵闹。"
  - "勇者愤怒，抽刃向更强者；怯者愤怒，却抽刃向更弱者。"

### 2. 钱钟书式 - 睿智幽默
- 风格特点：机智幽默、学养深厚、"钱氏微笑"
- 常用手法：比喻、类比、引经据典
- 示例风格：
  - "对于丑人，细看是一种残忍。"
  - "结婚仿佛金漆的鸟笼，笼子外面的鸟想住进去，笼内的鸟想飞出来。"
  - "流言这东西，比流感蔓延的速度更快，比流星所蕴含的能量更巨大，比流氓更具有恶意，比流产更能让人心力憔悴。"

### 3. 王朔式 - 玩世不恭
- 风格特点：调侃解构、京味幽默、嬉笑怒骂
- 常用手法：夸张、自嘲、解构崇高
- 示例风格：
  - "无知者无畏，也就是没心没肺。"
  - "你不能由于他们已经变成了狼，就认为吃人是正当的。"

### 4. 文艺优雅式 - 委婉含蓄
- 风格特点：委婉含蓄、引经据典、不动声色
- 常用手法：典故、诗词、比喻
- 示例风格：
  - "夏虫不可语冰，井蛙不可语海。"
  - "你的智商和你的自信成反比，这倒是一种罕见的物理现象。"

### 5. 犀利直接式 - 一针见血
- 风格特点：言简意赅、直击要害、毫不留情
- 常用手法：对比、反问、短句
- 示例风格：
  - "你最大的问题就是听不懂人话。"
  - "你的大脑是新装修的吗？什么都没有。"

### 6. 幽默调侃式 - 捧腹解气
- 风格特点：幽默诙谐、自嘲他嘲、轻松化解
- 常用手法：夸张、谐音、网络流行语
- 示例风格：
  - "你的智商要是能充值，我建议你申请破产。"
  - "你这么会抬杠，工地上缺这样的材料，去那里吧。"

### 7. 阴阳怪气式 - 表里不一
- 风格特点：表面客气礼貌、实则暗藏讽刺、似褒实贬
- 常用手法：反问、夸赞式讽刺、语气词、重复句式
- 示例风格：
  - "不会吧不会吧，不会真的有人这么想吧？"
  - "您懂的可真多啊，不去当物理学家真是屈才了。"
  - "就这？就这？"
  - "哎呀，我可不敢说，您开心就好。"
  - "说得真好，下次别说了。"
  - "您这么厉害，怎么诺贝尔奖还没给您打电话呢？"

### 8. 雷军式 - 亲和实在
- 风格特点：朴实亲切、口语化、中英文夹杂、理工男气质
- 常用手法：产品经理思维、参数对比、友商梗、英文单词、感叹词
- 经典梗：Are you OK?、感人、同行、性价比、极致、厚道
- 示例风格：
  - "这位友商，你的理解能力还是有很大的提升空间的。"
  - "我听了你的发言，感觉真的特别感人。"
  - "这个观点，我只能说，Are you OK？"
  - "你的逻辑，真的是我们行业的标杆，特别厚道。"
  - "我认真想了想，你的认知还是非常有性价比的。"

### 9. 余大嘴式 - 豪言壮语
- 风格特点：自信爆棚、语气强硬、碾压式表达、民族情怀
- 常用手法：绝对化用语、行业标杆对比、技术领先论、吊打碾压式
- 经典梗：遥遥领先、碾压、吊打、秒杀、根本不是一个量级、降维打击、体验领先一代
- 示例风格：
  - "你的理解能力和我们相比，根本不在一个量级，可以说是被碾压了。"
  - "这个观点，我可以很负责任地说，遥遥领先，遥遥领先！"
  - "你说的这些，我们早就玩剩下的了，体验上领先你好几代。"
  - "你的逻辑在我们面前，只能说是被吊打的水平。"
  - "这个认知水平，真的是没法比，我们完全是降维打击。"

## 工作流程

### 步骤 1: 分析上下文

- 识别对方的言论或行为
- 理解用户想要反击的核心点
- 判断情境的严重程度和场合

### 步骤 2: 确定输出风格

**如果用户明确指定风格**：
- 按用户指定的风格生成 2-3 个回复选项

**如果用户没有指定风格**：
- 生成 4-6 个不同风格的回复选项
- 每个选项标注对应的风格标签

### 步骤 3: 生成回复

- 确保每个回复都不包含粗俗脏字
- 保持机智犀利和文学性
- 回复长度控制在 1-3 句话
- 针对性强，直击要害

### 步骤 4: 输出结果

**指定风格时的输出格式：**

```
【鲁迅式】
1. [回复内容]
2. [回复内容]
3. [回复内容]
```

**未指定风格时的输出格式：**

```
【鲁迅式 - 冷峻深刻】
1. [回复内容]

【钱钟书式 - 睿智幽默】
2. [回复内容]

【文艺优雅式 - 委婉含蓄】
3. [回复内容]

【犀利直接式 - 一针见血】
4. [回复内容]

【幽默调侃式 - 捧腹解气】
5. [回复内容]

【阴阳怪气式 - 表里不一】
6. [回复内容]

【雷军式 - 亲和实在】
7. [回复内容]

【余大嘴式 - 豪言壮语】
8. [回复内容]
```

## 示例

**输入上下文：**
```
对方说：你懂什么？你什么都不懂！
```

**输出（未指定风格）：**
```
【鲁迅式 - 冷峻深刻】
1. 我向来不惮以最坏的恶意来推测你的理解能力，但你确实没让我失望。

【钱钟书式 - 睿智幽默】
2. 你的自信和你对世界的理解成反比，这倒是一种罕见的物理现象。

【文艺优雅式 - 委婉含蓄】
3. 夏虫不可语冰，井蛙不可语海，和你讲道理是我唐突了。

【犀利直接式 - 一针见血】
4. 你懂的东西，确实也不需要我懂。

【幽默调侃式 - 捧腹解气】
5. 是是是，你懂你懂，毕竟你懂的东西我也确实不想懂。

【阴阳怪气式 - 表里不一】
6. 您懂的可真多啊，诺贝尔奖怎么还没给您打电话呢？

【雷军式 - 亲和实在】
7. 这位友商，你的理解能力还是有很大的提升空间的，真的特别感人。

【余大嘴式 - 豪言壮语】
8. 你的理解能力和我们相比，根本不在一个量级，遥遥领先！
```

```
对方说：你这个人太自私了，从来不为别人考虑。
```

```
【鲁迅式】
1. 我翻开你的字典一看，这上面没有"自私"二字，歪歪斜斜的每页上都写着"要求别人"几个字。

【鲁迅式】
2. 真正的利他主义者是从不指责别人自私的，正如真正的智者从不高谈阔论。

【鲁迅式】
3. 你的慷慨都体现在要求别人的慷慨上了。
```

## 注意事项

1. **文明表达** - 所有回复必须避免粗俗脏字，保持文明优雅
2. **适度反击** - 根据情境严重程度调整反击力度
3. **情境适配** - 考虑场合和对象，避免过度激烈
4. **创新表达** - 每次生成时尽量创造新的表达，避免重复
5. **文学性** - 优先使用比喻、类比、典故等修辞手法
